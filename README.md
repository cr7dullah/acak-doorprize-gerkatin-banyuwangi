# 🎁 Acak Doorprize DPC GERKATIN Kabupaten Banyuwangi

Aplikasi sederhana untuk mengacak nomor doorprize peserta.

## 🏆 Fitur

- Acak nomor peserta 001–079
- Nomor yang sudah keluar tidak akan muncul lagi
- Menampilkan daftar angka yang sudah keluar
- Jumlah doorprize dapat diatur
- Jumlah hadirin dapat diatur
- Tampilan cocok untuk HP dan komputer
- Logo DPC GERKATIN Kabupaten Banyuwangi

## 📌 Penggunaan

1. Masukkan jumlah doorprize.
2. Masukkan jumlah hadirin.
3. Klik tombol **ACAK**.
4. Nomor pemenang akan muncul.
5. Klik **ACAK** lagi untuk pemenang berikutnya.
